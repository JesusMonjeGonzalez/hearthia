# Hearthia

The self-tending fire for local models — a control plane for llama.cpp on Apple Silicon.

Models are **cold** (on disk), **kindling** (loading), or **warm** (in RAM); Hearthia
tends the fire: TTL auto-unload, follow rules, verified downloads, and a dashboard.

Status: pre-release (v1 under construction — see the design spec in
`~/llm-stack/docs/superpowers/specs/2026-07-11-hearthia-design.md`).
